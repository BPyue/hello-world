# 匿名漂流瓶（微信小程序原型）

这是一个“匿名漂流瓶”小程序的静态原型页面，适合先验证产品交互，再迁移到微信小程序框架实现。

## 已实现功能

- 扔瓶子：输入匿名内容与心情标签后投入大海。
- 语音输入：支持浏览器语音转文字（不支持时自动降级为手动输入）。
- 捞瓶子：从“海里”随机捞取陌生人的瓶子。
- 匿名回复：可对捞到的瓶子发送匿名回复。
- 举报功能：对当前捞到的瓶子发起投诉举报并记录举报原因。
- 我的瓶子：查看自己投出的瓶子与回复数量。
- 本地持久化：基于 `localStorage` 存储数据，刷新页面后仍可保留。

## 本地运行

直接打开 `index.html` 即可体验，或启动本地静态服务：

```bash
python3 -m http.server 4173
```

然后访问：`http://localhost:4173`

## 后续迁移建议（微信小程序）

- 视图层：将页面拆分为 `pages/throw`、`pages/sea`、`pages/mine`。
- 状态管理：将本地 `localStorage` 替换为 `wx.setStorageSync` 或云开发数据库。
- 语音能力：将网页 `SpeechRecognition` 替换为微信小程序录音与语音识别能力。
- 举报流程：将本地举报记录上报服务端，并接入审核/风控策略。
